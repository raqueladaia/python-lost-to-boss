Example data for "Python: From Lost to Boss I" (Part 7)
=======================================================

ALL DATA IN THIS FOLDER IS SYNTHETIC. It was simulated to look like a real
von Frey experiment so you can practice; it does not come from real mice.

data.xlsx / data.csv   one row per mouse and test day: the up-down series
                       (x = withdrawal, o = no withdrawal), the last filament
                       and the 50% withdrawal threshold in grams
metadata.xlsx          one row per mouse: cage, sex, group, surgery date
                       (control = sham surgery, experimental = spared nerve injury)

The thresholds follow the up-down method (Chaplan et al. 1994, J Neurosci
Methods 53:55-63).
