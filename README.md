# Python: From Lost to Boss I

A free, self-paced Python course for researchers who want to stop copy-pasting in Excel and start analyzing their data with Python. In seven parts it goes from installing Python to opening Excel files and plotting a behavioral dataset. Every exercise comes as a script to solve and a solved version to check yourself.

**Take the course: [sandovalortega.com/python-lost-to-boss-1](https://sandovalortega.com/python-lost-to-boss-1/)**

By [Raquel Adaia Sandoval Ortega](https://sandovalortega.com/). The course started as a live workshop in 2024.

| Part | Topic |
|---|---|
| 1 | Setting up your laptop: Python, VS Code, repositories and environments |
| 2 | First contact with Python: libraries, data types, run vs. debug |
| 3 | Data structures: tuples, lists, vectors and matrices |
| 4 | Data storage: dictionaries and DataFrames |
| 5 | Plotting with Matplotlib and seaborn |
| 6 | Flow control: if, for, while |
| 7 | Opening CSV and Excel files: a von Frey dataset |

## Use the course offline

Download this repository (Code → Download ZIP) and open `site/index.html` in a browser. It works without a server. The scripts and data are in `site/downloads/`; `site/downloads/lost-to-boss-all-files.zip` holds all of them.

## About the example data

The von Frey data in Part 7 is **synthetic**: simulated up-down sessions, with the 50% threshold computed as in [vf_updown_analysis](https://github.com/raqueladaia/vf_updown_analysis). Control mice had a sham surgery; experimental mice had a spared nerve injury (SNI).
